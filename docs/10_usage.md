# 사용법 — 자막 및 TC 생성기

- 카테고리: `USAGE`
- 근거: `subtitle-tc-generator` README (2026-09-17 기준)
- 섹션 머리의 `[U-01]` 같은 표지를 답변에 인용한다
- 여기 없는 옵션·기능을 있다고 답하지 않는다. 없으면 `FEEDBACK`(건의)로 안내한다

## [U-01] 프로그램 개요와 두 가지 실행 방식

- 영상·자막 파일로 TC(자막이 뜨고 지는 시각)와 자막 초안을 만들고, 발주처 규정으로 검사·교정하는 도구
- 실행 방식 두 가지
  - **화면(Windows 실행 파일)**: `dist/자막생성기/자막생성기.exe`. 파이썬 없이 돈다
  - **명령줄**: `python -m checker ...`
- 화면과 명령줄은 같은 작업 단계를 쓴다

## [U-02] 작업 단계

- 소재: 자막 만들기 — 영상 → 전사 → 재분할 → 스포팅
- 번역: ① 1차 번역 → ② 번역 감수(회차) → ③ 자막 윤문·QA
- 한국어: ② 한국어 교정 → ③ 자막 QA
- 조사: 용어표, 캐릭터 문서
- 단계마다 보는 것이 하나다
  - 1차 번역은 오역만 본다
  - 2차는 용어·맥락·말투
  - 3차는 말맛·간결·문장부호와 **글자 수**. 글자 수를 앞 단계에서 맞추면 뜻이 먼저 깎인다
- 번역 검증
  - 1차 번역 직후: 원문과 전수 대조(화자 표시·용어·부정·숫자)
  - 마지막: 역번역 — 번역을 원어로 되돌려 원문과 비교

## [U-03] 화면(데스크톱 앱) 쓰기

- 영상·파형·자막 표를 한 화면에 두고 단추와 `단계(&S)` 메뉴로 단계를 돌린다
- 단계마다 직전 결과 요약이 붙는다
- 영상 재생은 libmpv, 파형은 자체 계산
- 결과는 화면에 넘기기 전에 `.work/`에 먼저 남는다 — 화면이 멈춰도 결과는 남는다
- **[도움말 → 진단]**: 무엇을 찾았고 무엇이 없는지 프로그램이 스스로 알려 준다. 설치·실행 문제는 여기부터 본다
- 사용자 자료 위치: `%APPDATA%\자막생성기\` (전사 모델·프로파일·기록)
  - 프로그램 폴더는 다시 빌드하면 지워지므로 큰 모델을 거기 두지 않는다
  - 옛 이름 `자막편집기` 폴더가 이미 있으면 그것을 계속 쓴다

## [U-04] 명령줄 — 규정 검사 기본

- 설치: `pip install -r requirements.txt`
- 검사 예
  - `python -m checker 파일.srt -p netflix -l ko -k sdh`
  - `python -m checker 파일.srt -p netflix -l en -k translation --json`
- 옵션
  - `-p`: 발주처(netflix / disney / coupang)
  - `-l`: 언어(ko, en …)
  - `-k`: 종류(`sdh` / `translation`)
  - `--json`: JSON으로 출력
  - `--list`: 쓸 수 있는 규정 프로파일 목록
- **`-p`·`-k`를 빼면 경고가 뜬다.** 발주처를 안 주면 netflix로, 종류를 안 주면 translation으로 진행한다. SDH 파일을 translation으로 검사하면 효과음 규칙이 통째로 빠진다
- 종료 코드: 위반이 있으면 1, 없으면 0

## [U-05] 검사 리포트 읽는 법

- 위반마다 **조항 번호를 인용**한다(예: `Korean TTSG I.13`)
- `[자동]`: 기계가 고칠 수 있는 위반
- `[확인]`: 사람이 판단해야 하는 위반
- `미구현 검사`: 프로파일에는 있지만 아직 구현하지 않은 검사. 통과했다는 뜻이 **아니다**
- 리포트 머리에 규정 근거의 성격이 나온다
  - 넷플릭스: 공식 스타일 가이드 (`official: true`)
  - 디즈니+·쿠팡플레이: 작업자 실무 자료 (`official: false`) — 공식 문건을 아직 확보하지 못했다

## [U-06] 자동 교정 (`--fix`)

- `python -m checker 파일.srt -l ko -k sdh --fix` → `파일.fixed.srt`로 나간다
- `-o 출력.srt`로 출력 파일 이름을 정할 수 있다
- **원본을 덮어쓰지 않는다**
- 고치는 것은 자동 규칙 중 **고치는 기능이 실제로 있는 것만**이다
  - 자동 표시지만 기계가 정할 수 없는 자리(예: 대괄호를 어디서 닫을지)는 "자동 표시지만 기계가 못 고치는 것"으로 따로 알린다
- 검사는 교정 **뒤에** 다시 돈다 — 교정이 새로 만든 위반까지 잡기 위해서다

## [U-07] 타임코드 교정과 고정

- `--fix-timing --fix`: 영상 없이 타임코드를 규정 범위 안으로 맞춘다
- `--video 영상.mkv --spot`: 영상을 보고 스포팅(인점·아웃점) 제안
- 수렴 우선순위: 겹침 해소 → 최소 표시 시간 → 자막 간 간격 → 최대 표시 시간 → 읽기 속도
- **인점은 되도록 건드리지 않는다.** 끝내 못 맞춘 자리는 고쳤다고 하지 않고 남은 문제로 알린다
- `--lock-timecodes`: **타임코드를 절대 건드리지 않는다**
  - TC 작업이 끝난 파일을 받아 번역만 하는 경우를 위한 옵션
  - 수렴·스포팅뿐 아니라 **재분할도 막는다**(나누면 경계가 새로 생기기 때문)
  - `--fix-timing`과 함께 주면 조용히 무시하지 않고 **오류로 막는다**
  - 들어가지 않는 번역은 자막을 나누지 않고 검사가 잡아 사람이 문장을 줄인다

## [U-08] 자막 초안 만들기 (`--generate`)

- SDH 초안: `python -m checker --generate --video ep01.mkv -l ko -k sdh`
- 원어 대조 + 한국어 초벌 번역: `--generate --video ep01.mkv --script ep01.docx -l ko -k translation --translate`
- 전사: ffmpeg 내장 whisper / 말소리 구간: Silero VAD(없으면 음량) / 번역: 로컬 Ollama
- **원고가 컴퓨터 밖으로 나가지 않는다**
- 원어 스크립트는 워드·텍스트·PDF를 읽는다
- 전사와 스크립트 어느 쪽도 정답으로 두지 않는다. 어긋난 자리는 표시만 한다
- 소리를 못 찾은 스크립트 줄은 지우지 않고 길이 0으로 남긴다
- 영상에 자막 트랙이 이미 있으면 생성 전에 경고한다

## [U-09] 화면 캡션·효과음 (`--ocr` / `--sfx`)

- whisper는 말소리만 받아 적는다. 화면 글자와 대사 없는 구간의 소리는 따로 읽는다
- 둘 다 두 단계다
  - 1단계 보고만: `--ocr-scan`, `--sfx-scan`
  - 2단계 실제로 얹기: `--ocr`, `--sfx`
- 화면 캡션
  - `--ocr-scan --video ep01.mkv --ocr-lang ko`: 캡션 목록만
  - `--generate ... --ocr --fn-marker bracket`: 얹기. 마커 지정 필수
  - `--ocr-hardsub`: 자막 트랙 없이 영상에 자막이 박힌 경우 초안 srt. 71분 영상 기준 최대 7~8시간. 끊겨도 이어서 돈다
- 효과음
  - `-l ko -k sdh` 전용
  - 얹은 효과음은 신뢰도와 상관없이 **전부 "확인 필요"** 로 표시된다

## [U-10] 번역 (`--translate`)

- `python -m checker 파일.srt -l ko -k translation --translate --passes 3`
- `--max-passes 6 --settle-at 2`: 결과가 잠잠해지면 멈춘다
- `--backtranslate`: 역번역 검증. 점수 기준선이 아니라 나쁜 순서로 개수만큼 보여 준다(`--backtranslate-worst`, 기본 20)
- `--cast ep01.characters.tsv`: 인물별 말투 어긋남 검사
- 회차 상한에 걸려 멈춘 것과 다 끝난 것을 문구로 구분해 알린다

## [U-11] 한국어 교정 (`--korean`)

- `python -m checker 파일.srt -l ko -k sdh --korean --ksc-path 교정기경로`
- 경로 대신 `KSC_PATH` 환경변수도 된다. 옆 폴더에 있으면 자동으로 찾는다
- 교정기에는 **대사만** 넘어간다. 화자 표시·효과음·음표·2인 화자 하이픈·서식 태그는 빼고 넘긴 뒤 제자리에 되돌린다
- 결과 표시: 교정 제안 / 확인 필요 두 가지로 나뉜다
- 리포트 표시(창구 답변에는 쓰지 않는다): 교정 제안 `K01` · 확인 필요 `K02`
- 교정기에는 kiwipiepy(약 310MB)와 국립국어원 API 키가 필요하다. 없으면 한국어 교정만 건너뛰고 규정 검사는 계속한다

## [U-12] 중간 결과 (`.work/`)

- 기본으로 켜져 있다. `--no-work`로 끈다
- `ep01.work/` 안에 단계별 결과가 남는다
  - `manifest.json`: 단계별 모델·시각·걸린 시간·바뀐 줄·멈춘 이유
  - `01-generate.srt`: 타임코드 확정본(이후 바뀌지 않음)
  - `02-first.srt`, `03-revise-2차.srt` …: 단계·회차별 결과
- 번역이 뒷 단계에서 깨져도 처음부터 다시 하지 않아도 된다
- 이후 단계가 타임코드를 옮기면 기록에 경고로 남는다
- 기록 남기기가 실패해도 본 작업은 멈추지 않는다

## [U-13] 조사 도구

- `--terms`: 용어표(KNP 시트용)
- `--characters --wiki 위키이름 --work-title "작품 제목"`: 캐릭터 문서(말투·인물 관계)
  - 밖으로 나가는 것은 **작품 제목과 인물 이름뿐**. 대사·대본은 나가지 않는다
  - 위키는 사람이 지정한다. 짐작하지 않는다
- `--bookmarks 폴더/`: SubtitleEdit 북마크(첨삭) 모으기
- 캐릭터 문서와 KNP 시트는 다른 문서다 — KNP는 고유명사 표기, 캐릭터 문서는 말투·관계

## [U-14] Windows에서 끌어다 놓기

- `tools/`의 `.bat` 파일 위로 자막 파일이나 폴더를 끌어다 놓으면 된다
- 파일 이름에 발주처·언어·종류가 들어 있어 SDH와 번역을 헷갈릴 일이 없다
  - `netflix-ko-sdh-check.bat` / `-fix.bat` / `-spot.bat`
  - `netflix-ko-translation-check.bat` / `-fix.bat` / `-spot.bat`
  - `netflix-ko-sdh-practice-check.bat`: 공식 규정 + 실무 관행
  - `netflix-en-translation-check.bat`
  - `disney-ko-sdh-check.bat` / `-fix.bat`, `disney-ko-translation-check.bat` / `-fix.bat`
  - `coupang-ko-sdh-check.bat` / `-fix.bat`, `coupang-ko-translation-check.bat` / `-fix.bat`

## [U-15] 장르 (`--genre`)

- `documentary` / `drama` / `variety` 중 하나를 준다
- 장르는 프롬프트가 아니라 **규정 프로파일 층**이다. 장르에 따라 자막 길이 기준 등이 달라진다
  - 구체 수치는 비공개 실무 자료에서 왔으므로 이 창구에서 안내하지 않는다
- 멜로·느와르 프로파일은 없다. 멜로는 드라마 기본값이고, 거친 표현은 장르가 아니라 캐릭터가 정한다
- 다큐의 합니다체는 비율만 보여 주고 위반으로 잡지 않는다

## [U-16] 화면자막 겹침 (`--fn-marker` / `--collision`)

- 대사 자막과 화면 번인 자막이 겹칠 때 처리 방식은 **작업마다** 정해진다. 그래서 기본값이 없다
- 작업 시작 전에 정해서 준다
  - `--fn-marker`: 화면자막 표식
  - `--collision`: `move_dialogue`(대사 자막을 옮긴다) / `dialogue_only`(대사 자막만 남긴다) / `keep_both`(둘 다 둔다)
- **정하지 않으면 위치 검사 자체를 하지 않는다** — 추측해서 옮기면 납품물이 틀어진다
