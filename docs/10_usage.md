# 사용법 — 자막 및 TC 생성기

- 카테고리: `USAGE`
- 근거: `subtitle-tc-generator` 데스크톱 앱(`app/`)과 Subtitle Edit 플러그인(`plugin/se4/`)의 화면 문구 (2026-09-17 확인)
- 섹션 머리의 `[U-01]` 같은 표지를 답변에 인용한다
- **이 창구의 사용자는 코딩을 모른다.** 명령어·옵션·설치 명령을 안내하지 않는다. 화면의 메뉴·단추·체크 이름으로만 안내한다
- 여기 없는 기능을 있다고 답하지 않는다. 없으면 `FEEDBACK`(건의)로 안내한다

## [U-01] 프로그램 개요와 쓰는 곳 두 가지

- 영상·자막 파일로 TC(자막이 뜨고 지는 시각)와 자막 초안을 만들고, 발주처 규정으로 검사·교정하는 프로그램
- 쓰는 곳 두 가지
  - **데스크톱 앱**: `자막생성기.exe`를 두 번 눌러 켠다. 창 제목은 `자막 및 TC 생성기`
  - **Subtitle Edit 플러그인**: Subtitle Edit의 [도구] 메뉴 → `자막 규정 검사·교정 / 영상에서 자막 만들기...`. 창 제목은 `자막 규정 검사기`
- 설치와 플러그인 붙이기는 사용자가 직접 하지 않는다 — 안 되면 [U-14] 방법으로 알려 준다

## [U-02] 작업 단계 (데스크톱 앱)

- 오른쪽 `작업 단계` 칸에 묶음별로 단추가 있다. 같은 기능이 `단계(&S)` 메뉴에도 있다
  - 소재: [자막 만들기]
  - 번역: [① 1차 번역] → [② 번역 감수](`회차` 1~5) → [③ 자막 윤문·QA]
  - 한국어: [② 한국어 교정] → [③ 자막 QA]
  - 조사: [용어표] [캐릭터 문서]
- 단추 줄 아래에 직전 결과 요약이 회색 글자로 붙는다
- 단추가 꺼져 있으면 단추 위에 마우스를 올려 이유를 본다
  - [자막 만들기]는 영상이 필요하다: [파일 → 영상 열기...]
  - 나머지는 자막이 필요하다: [자막 만들기]로 만들거나 [파일 → 자막 열기...]
- 단계마다 보는 것이 하나다
  - 1차 번역은 오역만 본다
  - 2차 감수는 용어·맥락·말투
  - 3차 윤문은 말맛·간결·문장부호와 **글자 수**. 글자 수를 앞 단계에서 맞추면 뜻이 먼저 깎인다
- 작업 중에는 상태줄에 경과 시간이, 아래 `진행 기록` 칸에 진행 내용이 나온다. 실패하면 "작업을 마치지 못했습니다" 창이 뜬다

## [U-03] 파일 열기·저장과 화면 배치 (데스크톱 앱)

- 파일은 [파일] 메뉴로 연다
  - `영상 열기...` (Ctrl+O): mp4·mkv·mov·avi·ts·m4v·webm
  - `자막 열기...` (Ctrl+Shift+O): srt·vtt
  - `원어 대본 열기...` (Ctrl+Alt+O): 워드·텍스트·PDF. 자막이 열려 있으면 순서대로 짝지어 `원어` 칸에 채운다. 줄 수가 다르면 뒤로 갈수록 어긋난다고 알린다
- 화면: 왼쪽 위 영상, 오른쪽 위 자막 표(`#`·`시작`·`끝`·`길이`·`원어`·`자막`), 아래 파형
  - 자막 표에서는 `자막` 칸만 고칠 수 있다. 행을 두 번 누르면 영상이 그 자리로 간다
- [보기] 메뉴로 화면 비율을 한 번에 바꾼다: `타임코드 작업 (파형 크게)` Ctrl+1 · `번역 작업 (표 크게)` Ctrl+2 · `영상 크게` Ctrl+3 · `고르게` Ctrl+0
- **[파일 → 자막 저장]** (Ctrl+S)
  - **원본 파일을 덮어쓰지 않는다.** 저장 위치와 이름은 파일 창에서 사람이 정한다. 기본 이름은 `원본이름.edited.srt`
  - 늘 SRT로 저장한다
  - `원어` 칸에 내용이 있고 설정 `원어 자막도 함께 저장`이 켜져 있으면 `저장이름.원어.srt`도 함께 저장한다

## [U-04] 발주처·종류 고르기

- 데스크톱 앱: 위쪽 `작업` 툴바
  - `플랫폼`: netflix / disney / coupang, 그리고 작업 기준 창에서 만든 발주처 기준
  - `종류`: translation(번역 자막) / sdh(SDH 자막)
  - `원어`: 영상 말소리 언어(en / ko / auto). 검사 언어가 아니다
- Subtitle Edit 플러그인: 창 위쪽 `플랫폼`·`종류`
- **종류를 잘못 고르면 기준이 달라진다.** SDH 자막을 translation으로 검사하면 효과음 같은 SDH 규칙을 통째로 보지 않는다
- 넷플릭스 기준은 공식 스타일 가이드에서, 디즈니+·쿠팡플레이 기준은 작업자 실무 자료에서 왔다

## [U-05] 검사 결과 읽는 법

- 데스크톱 앱: 검사가 끝나면 아래에 `검사 결과` 칸이 열린다(지적이 0건이면 닫힌다)
  - 칸 세 개: `자막`(자막 번호) · `규칙`(검사 항목과 `자동`/`확인`) · `내용`(설명)
  - `자동`: 기계가 고칠 수 있는 항목 / `확인`: 사람이 판단해야 하는 항목
  - 행을 두 번 누르면 그 자막 행으로 가고 영상도 그 자리로 간다
  - 상태줄에 "③ 자막 QA 완료 — 남은 지적 N건"처럼 남은 지적 수가 나온다
- Subtitle Edit 플러그인: 창 가운데 글 칸에 전체 리포트가 나온다
  - 위반마다 넷플릭스 가이드 조항을 인용한다(예: `Korean TTSG I.13`)
  - `[자동]`: 기계가 고칠 수 있는 위반 / `[확인]`: 사람이 판단해야 하는 위반
  - `미구현 검사`: 기준에는 있지만 아직 검사하지 않는 항목. 통과했다는 뜻이 **아니다** — 사람이 직접 봐야 한다

## [U-06] 자동 교정

- 데스크톱 앱: **[③ 자막 QA]를 누르면 고칠 수 있는 것을 곧바로 자막 표에 반영**하고, 남은 지적만 `검사 결과`에 보여 준다
  - [③ 자막 윤문·QA]도 윤문 뒤에 같은 교정·검사를 한다
  - 되돌리기 단추는 없다. 원본 파일은 그대로이므로 결과가 마음에 들지 않으면 원본을 다시 연다
  - 반영된 자막은 [파일 → 자막 저장]으로 새 이름으로 저장한다
- Subtitle Edit 플러그인
  - [③ 자막 검사만]: 자막을 건드리지 않고 검사만 한다
  - [③ 자막 검사 + 교정]: 고친 결과를 만든다
  - **[★ 결과를 SE로]를 누르기 전에는 SE의 자막이 바뀌지 않는다.** 리포트를 먼저 보고 사람이 정한다. 반영한 뒤에도 SE에서 Ctrl+Z로 되돌릴 수 있다
- 고치는 것은 자동 항목 중 **기계가 정할 수 있는 것만**이다. 대괄호를 어디서 닫을지처럼 사람이 정해야 하는 자리는 남은 지적으로 남는다

## [U-07] 타임코드 다루기

- 데스크톱 앱에서 손으로 맞추기
  - 파형 아래쪽 자막 구간 가장자리를 끌어 인점·아웃점을 옮긴다. 놓으면 상태줄에 시작~끝이 나온다
  - `F5` 인점을 지금 위치로 · `F6` 아웃점을 지금 위치로
  - `Ctrl+Space` 재생 위치에서 나누기 · `Alt+Space` 다음 자막과 합치기
  - 이웃 자막을 침범하거나 자막이 뒤집히면 적용하지 않고 알린다
  - 나누기와 인점·아웃점 지정은 영상이 열려 있어야 된다
- 데스크톱 앱의 [① 1차 번역]은 타임코드를 바꾸지 않는다
- **받은 타임코드를 절대 건드리면 안 될 때**(TC 작업이 끝난 파일에 번역만 할 때): Subtitle Edit 플러그인
  - [② 받은 TC에 번역만]: 받은 타임코드는 건드리지 않고 번역만 한다. 칸에 안 들어가는 번역은 자막을 나누지 않고 검사가 잡아 사람이 문장을 줄인다
  - `타임코드 고정(받은 TC)` 체크: 검사·교정 때도 타임코드를 옮기지 않는다
  - `타임코드 수렴` 체크: 타임코드를 규정 범위 안으로 맞춘다. **고정과 함께 켜면 고정이 이긴다**

## [U-08] 영상에서 자막 만들기

- 데스크톱 앱: [파일 → 영상 열기...] 뒤 [자막 만들기]
  - `종류`가 translation이면 먼저 원어 대본 파일을 고르는 창이 뜬다(없으면 취소)
  - `만들 때 번역까지` 체크: 만든 뒤 1차 번역까지 이어서 한다
  - 끝나면 만든 자막 수와 **봐야 할 자리** 수를 알린다. 봐야 할 자리는 `검사 결과`에 `확인`으로 나온다
  - 대본을 줬으면 대본에서 온 것, 대본에 없어 소리로 채운 것, 대본에 있는데 소리가 없는 것의 수를 알린다
  - 만들기 단계는 자동 교정을 하지 않는다
- Subtitle Edit 플러그인: `영상`·`원어 대본`을 [찾기]로 고른 뒤 [① 영상만 있다 → 자막 만들기]. `한국어 초벌 번역(만들기)` 체크로 번역까지 한다
- **원고가 컴퓨터 밖으로 나가지 않는다** — 받아 적기와 번역 모두 이 컴퓨터 안에서 한다
- 소리와 대본 어느 쪽도 정답으로 두지 않는다. 어긋난 자리는 표시만 한다
- 소리를 못 찾은 대본 줄은 지우지 않고 길이 0으로 남긴다
- 영상 안에 자막이 이미 들어 있으면 만들기 전에 알린다
- 시간이 오래 걸린다. 진행 기록에 예상 시간이 나온다

## [U-09] 화면 캡션 읽기 (데스크톱 앱)

- 툴바 `화면 캡션도 OCR로 읽기`를 켜고 [자막 만들기]를 하면 화면에 뜬 글자도 읽어 자막에 얹는다
- **먼저 작업 기준 창에서 `화면자막 표식`을 정해야 한다.** 안 정하면 "화면자막 표식이 정해지지 않았습니다" 창이 뜨고 멈춘다([U-16])
- 읽을 언어는 작업 기준 창 → `저장·파형·도구` → `화면 캡션 언어`
- 오래 걸린다 — 진행 기록에 예상 시간이 나온다
- 읽어 얹은 캡션은 자막 표에서 **갈색 글자**로 보인다. 확인이 필요할 수 있다

## [U-10] 번역 (데스크톱 앱)

- [① 1차 번역]: 타임코드는 그대로 두고, 지금 글자를 `원어` 칸으로 옮긴 뒤 번역한다. 확인할 자리는 `검사 결과`에 `번역`으로 표시된다
- [② 번역 감수]: 옆 `회차`(1~5, 기본 2)만큼 돈다. **결과가 잠잠해지면 상한 전에 멈추고**, 왜 멈췄는지 진행 기록에 남긴다. 바뀐 곳도 진행 기록에 나온다
- [③ 자막 윤문·QA]: 윤문한 뒤 한국어 교정과 규정 교정·검사까지 이어서 한다
- 자막 파일 옆에 KNP 시트가 있으면 번역에 자동으로 쓴다
- 번역도 이 컴퓨터 안의 번역 모델로 한다. 원고가 밖으로 나가지 않는다

## [U-11] 한국어 교정

- 데스크톱 앱: [② 한국어 교정]. 교정기가 고친 문장을 자막 표에 반영한다. 규정 자동 교정은 하지 않는다
- Subtitle Edit 플러그인: `한국어 교정기` 체크를 켜고 검사한다
- 교정기에는 **대사만** 넘어간다. 화자 표시·효과음·음표·서식은 빼고 넘긴 뒤 제자리에 되돌린다
- 결과는 '교정 제안'과 '확인 필요' 두 가지로 나뉜다
- 리포트 표시(창구 답변에는 쓰지 않는다): 교정 제안 `K01` · 확인 필요 `K02`
- "한국어 교정기를 찾지 못했습니다"가 뜨면 [U-14]대로 진단 창을 보고 알려 준다. 교정기가 없어도 규정 검사는 된다

## [U-12] 중간 결과 폴더 (`.work`)

- 데스크톱 앱은 단계마다 결과를 **화면에 넘기기 전에** 폴더에 먼저 남긴다 — 화면이 멈춰도 결과는 남는다
  - [자막 만들기]: 영상 옆 `영상이름.work` 폴더
  - 번역·감수·윤문: [파일 → 자막 열기...]로 연 자막 파일 옆 `자막이름.work` 폴더. 영상에서 만든 자막을 저장만 한 경우에는 남지 않는다
- 폴더 안 파일: `01-generate`(만들기 결과), `02-first`(1차 번역), `03-revise-…`(감수 회차), `04-polish-…`(윤문), `05-final`
- 뒷 단계에서 번역이 깨져도 처음부터 다시 하지 않아도 된다 — 앞 단계 파일을 [자막 열기...]로 열어 거기서 잇는다

## [U-13] 조사 도구 (데스크톱 앱)

- [용어표]: 자막의 용어를 모아 `자막이름.terms.tsv`로 쓴다. 위키백과에서 용어를 찾고 설명을 붙인다. 결과 목록은 `검사 결과` 칸에도 나온다
- [캐릭터 문서]: `자막이름.characters.tsv`와 `.characters.md`를 쓴다
  - 표의 '말투 지정' 칸을 채우면 이후 감수·윤문에 쓰인다(앱을 켜 둔 동안)
- 자막 파일을 연 적이 없으면 파일 이름이 `용어표.terms.tsv`·`캐릭터.characters.*`가 된다
- 캐릭터 문서와 KNP 시트는 다른 문서다 — KNP는 고유명사 표기, 캐릭터 문서는 말투·관계

## [U-14] 설치·실행이 안 될 때

- **[도움말 → 진단...]**을 연다. 무엇을 찾았고 무엇이 없는지 프로그램이 스스로 알려 준다
  - 줄마다 `[OK  ]` 또는 `[없음]`
  - 항목: `기록(log)` · `규정 파일` · `발주처 기준 자리` · `영상 재생(libmpv)` · `ffmpeg` · `전사(whisper 필터)` · `전사 모델` · `말소리 모델(VAD)` · `번역(로컬 모델)` · `한국어 교정기` · `교정기 계약`
  - 마지막 줄이 `모두 갖춰졌습니다.`면 설치는 문제가 없다
  - `[없음]`이 있으면 **그 기능만** 안 되고 나머지는 그대로 쓸 수 있다
- **설치는 직접 하지 않는다.** 진단 창의 `[없음]` 줄 이름을 그대로 적어 이 창구에 제보하면 담당자가 처리한다(`FEEDBACK`으로 접수)
- 영상이 안 열리고 "영상을 재생할 수 없습니다"가 뜨면 진단 창의 `영상 재생(libmpv)` 줄을 확인해 알려 준다
- Subtitle Edit [도구] 메뉴에 플러그인이 안 보이거나 플러그인 창에 [폴더 지정] 단추가 뜨면 설치 문제다 — 그대로 제보한다

## [U-15] 작업 기준 창

- 툴바 [작업 기준...]으로 연다. 맨 위에 지금 기준(플랫폼 / 종류 — 공식 문건인지 실무 자료인지)이 나온다
- 왼쪽 탭
  - `작업 기준(수치)`: 한 줄 글자 수, 최대 줄 수, 최소·최대 표시 시간, 읽기 속도, 자막 사이 최소 프레임
  - `이 작업에서 정할 것`: 화면자막 표식, 말자막과 겹칠 때, 옮길 자리([U-16])
  - `검사 규칙`: 규칙마다 `씀` 체크로 켜고 끈다
  - `단축키와 기능`: 키를 눌러 단축키를 바꾼다. 겹치면 묻는다. [기본값으로 되돌리기]
  - `저장·파형·도구`: 저장 이름 꼬리표, 원어 자막 함께 저장, 파형 확대, 말소리 구간·장면 전환 표시, 재생 위치 따라가기, 화면 캡션 언어 등
  - `적용 중인 값 전부`: 지금 적용되는 값을 읽기만 한다
- **원래 기준은 건드리지 않는다.** 아래 `발주처 이름`을 적고 저장하면 바꾼 값만 담은 새 기준이 생기고, `플랫폼` 목록에서 그 이름을 고르면 그 기준으로 검사한다
  - 이름을 비워 두고 저장하면 단축키와 설정만 저장한다
- `플랫폼` 목록 맨 아래 `＋ 새 기준 만들기...`로도 이 창이 열린다

## [U-16] 화면자막과 말자막이 겹칠 때

- 대사 자막과 화면에 박힌 글자가 겹칠 때 처리 방식은 **작업마다** 발주처가 정한다. 그래서 기본값이 없다
- 작업 시작 전에 정한다
  - 데스크톱 앱: 작업 기준 창 → `이 작업에서 정할 것` → `화면자막 표식` · `말자막과 겹칠 때` · `옮길 자리`
  - Subtitle Edit 플러그인: 창 위쪽 `화면자막` · `겹치면` · `옮길 자리`
- `말자막과 겹칠 때` 선택지
  - `move_dialogue`: 대사 자막을 `옮길 자리`로 옮긴다
  - `dialogue_only`: 대사 자막만 남긴다
  - `keep_both`: 둘 다 둔다
- **정하지 않으면(`(작업 시작 전 선택)` 그대로면) 위치 검사·교정을 하지 않는다** — 어디로 옮길지 모르는 채로 옮기면 납품물이 틀어진다
- 데스크톱 앱에서는 발주처 이름을 적고 저장해야 기준에 남는다([U-15])

## [U-17] 단축키 (데스크톱 앱)

- [도움말 → 단축키...] (F1)에서 전체 목록을 본다. 바꾸는 곳은 작업 기준 창 `단축키와 기능` 탭
- 기본 키
  - 재생: `Esc`·`Space` 재생/일시정지 · `Ctrl+Shift+←` 1프레임 뒤로 · `Ctrl+Shift+→` 1프레임 앞으로
  - 이동: `PgUp` 이전 자막 · `PgDown` 다음 자막 · `Ctrl+G` 자막 번호로 이동
  - 편집: `Ctrl+Space` 재생 위치에서 나누기 · `Alt+Space` 다음 자막과 합치기 · `Alt+Shift+Space` 대화로 합치기 · `Ctrl+-` 대화 하이픈 넣고 빼기 · `Ctrl+\` 줄바꿈 제거
  - 위치: `Alt+↑` 자막을 위로 · `Alt+↓` 자막을 아래로
  - 타임코드: `F5` 인점을 지금 위치로 · `F6` 아웃점을 지금 위치로
  - 파형: `Alt+=` 확대 · `Alt+-` 축소 · `Ctrl+휠` 확대·축소
