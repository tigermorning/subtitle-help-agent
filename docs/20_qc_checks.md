# 검사 결과 설명 — 넷플릭스 한국어 프로파일 검사 항목

- 카테고리: `QC_EXPLAIN`
- 근거: `subtitle-tc-generator`의 넷플릭스 규정 프로파일(`common` / `ko-translation` / `ko-sdh`)과 검사 구현 목록 (2026-09-17 확인)
- 규정 내용은 `docs/30_style_netflix.md`의 조항 요약을 함께 인용한다
- 섹션 머리의 `[Q-07]` 같은 표지를 답변에 인용한다

## [Q-00] 검사 결과 읽는 법과 이 창구가 설명하는 범위


- 판정 표시 (데스크톱 앱 `검사 결과` 칸의 `규칙` 칸은 `자동`/`확인`, Subtitle Edit 플러그인 리포트는 `[자동]`/`[확인]`)
  - `[자동]`: 기계가 고칠 수 있다. 데스크톱 앱은 [③ 자막 QA], 플러그인은 [③ 자막 검사 + 교정]으로 고친다(원본 파일은 그대로, `U-06`)
  - `[확인]`: 사람이 판단한다. 기계가 고치지 않는다
  - `미구현 검사`(플러그인 리포트에만 나온다): 기준에는 있으나 아직 검사하지 않는다. **통과가 아니다** — 사람이 직접 봐야 한다
- 이 창구가 설명하는 것: **넷플릭스 공식 가이드에 근거한 검사 항목**(아래 표)
- 이 창구가 설명하지 않는 것
  - 디즈니+·쿠팡플레이 프로파일 항목 — 근거가 비공개 실무 자료다
  - 넷플릭스 프로파일 안에서도 공식 가이드가 아닌 실무 자료에서 온 항목 — 같은 이유
    - 리포트 표시(창구 답변에는 쓰지 않는다): `C11`·`C12`·`C30`~`C33`
  - 위 항목을 물으면 근거를 지어내지 말고, 비공개 자료라 이 창구에서 근거를 안내할 수 없다고 답한다
- 검사 항목의 세 갈래
  - 넷플릭스 공통(번역·SDH 모두)
  - 한국어 번역 자막(Korean TTSG Section I)
  - 한국어 SDH(Korean TTSG Section II)
  - 같은 이름의 경고라도 번역 자막과 SDH는 기준이 다를 수 있다(예: 읽기 속도)
- 리포트 표시(창구 답변에는 쓰지 않는다): 규칙 번호 앞자리 `C`는 공통, `T`는 번역, `S`는 SDH

## [Q-01] 노출 시간 범위

- 리포트 표시(창구 답변에는 쓰지 않는다): 규칙 번호 `C01` · 검사 이름 `duration_out_of_range`
- 근거: `GR-1`, `TM-3`
- 판정: `[확인]`
- 뜻: 자막 하나가 화면에 떠 있는 시간이 최소보다 짧거나 최대(7초)보다 길다
- 고치는 법
  - 짧으면: 아웃점을 늘린다. 다음 자막과 붙어 못 늘리면 앞뒤 자막과 합친다(`TM-6`)
  - 길면: 자막을 둘로 나누거나 아웃점을 당긴다
  - 한꺼번에 맞추려면 Subtitle Edit 플러그인의 `타임코드 수렴` 체크(`U-07`). 단 `타임코드 고정(받은 TC)`과 함께 켜면 고정이 이긴다

## [Q-05] 자막 사이 간격

- 리포트 표시(창구 답변에는 쓰지 않는다): 규칙 번호 `C05` · 검사 이름 `gap_too_short`
- 근거: `TM-5`
- 판정: `[확인]`
- 뜻: 앞 자막이 끝나고 다음 자막이 시작하기까지 간격이 최소 간격보다 짧거나 두 자막이 겹친다
- 규정: 최소 2프레임. 24fps에서 3~11프레임 간격은 2프레임으로 닫는다
- 프레임 수는 영상 프레임레이트에 따라 밀리초가 달라진다(2프레임 = 23.976fps에서 약 83ms, 29.97fps에서 약 67ms)
- 고치는 법: 앞 자막 아웃점을 늘려 간격을 닫거나, 간격을 반 초 이상으로 벌린다
- 구현 범위: 2프레임 미만 간격·겹침만 잡는다. **3~11프레임 간격 닫기는 검사하지 않는다(미구현)** — 직접 확인한다

## [Q-06] 화면 글자와 위치 충돌

- 리포트 표시(창구 답변에는 쓰지 않는다): 규칙 번호 `C10` · 검사 이름 `position_collides_with_forced_narrative`
- 근거: `GR-5`
- 판정: `[자동]`
- 뜻: 대사 자막이 화면 글자 자리와 겹친다
- 처리: 작업 전에 정한 `말자막과 겹칠 때` 값을 따른다 — `move_dialogue`(대사 자막을 옮긴다) / `dialogue_only`(대사 자막만 남긴다) / `keep_both`(둘 다 둔다). 위아래 모두 글자가 있으면 읽기 쉬운 쪽에 둔다(`GR-5`)
- 주의: 겹침 처리 방식은 작업마다 달라 `화면자막 표식`·`말자막과 겹칠 때`를 정해야 검사한다(`U-16`)

## [Q-07] 한 줄 글자 수 초과 (번역)

- 리포트 표시(창구 답변에는 쓰지 않는다): 규칙 번호 `T01` · 검사 이름 `line_length_exceeded`
- 근거: `KO-I.2`
- 판정: `[확인]`
- 뜻: 한 줄이 **지금 작업 기준(발주처 프로파일)이 정한 글자 수**를 넘는다. 라틴 문자·공백·문장부호는 0.5자로 센다
  - 이 문서가 예로 드는 넷플릭스 한국어 기준은 16자다. 발주처마다 다르고, 작업 시작 전 [작업 기준...] 창에서 정한다(`U-15`)
- 고치는 법: 문장을 줄이거나 두 줄로 나눈다(최대 2줄). 줄바꿈은 아래 줄이 긴 모양이 좋다(`KO-I.11`)
- 기계가 고치지 않는 이유: 어디를 줄일지는 뜻을 아는 사람이 정해야 한다
