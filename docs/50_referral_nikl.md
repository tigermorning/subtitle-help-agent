# 범위 밖 안내 — 국립국어원 넘기기와 그 밖의 범위 밖

- 카테고리: `OUT_OF_SCOPE`
- 근거
  - 넷플릭스 한국어 가이드 `KO-I.21`: 가이드에 없는 언어 문제는 국립국어원을 참고하라
  - 국립국어원 누리집 (주소 2026-09-17 접속 확인)
- 섹션 머리의 `[R-01]` 같은 표지를 답변에 인용한다

## [R-01] 언제 국립국어원으로 넘기나

- 맞춤법·띄어쓰기·표준어·외래어 표기·문법 같은 **한국어 어문 규범** 질문
- 먼저 `docs/30_style_netflix.md`에 해당 조항이 있는지 본다
  - 있으면 `STYLE_RULE`로 조항 근거를 들어 답한다 (예: 줄 끝 마침표 → `KO-I.13`, 말줄임표 문자 → `KO-I.4`)
  - **없으면 답을 지어내지 않고** 국립국어원을 안내한다
- 넘길 때 하지 말 것
  - "보통은 ~가 맞습니다" 같은 추측 답변을 덧붙이지 않는다
  - 특정 표기가 맞다/틀리다를 판정하지 않는다

## [R-02] 안내할 국립국어원 서비스

- 국립국어원 누리집: https://www.korean.go.kr/
- 온라인가나다(어문 규범 질문 게시판): https://www.korean.go.kr/front/onlineQna/onlineQnaList.do
  - 질문을 직접 올리면 국립국어원이 답한다
- 한국어 어문 규범(한글 맞춤법·표준어 규정·외래어 표기법·로마자 표기법 원문): https://www.korean.go.kr/kornorms/main/main.do
- 표준국어대사전: https://stdict.korean.go.kr/
- 우리말샘(개방형 사전): https://opendict.korean.go.kr/

## [R-03] 자막 생성기의 한국어 교정 기능과의 관계

- 생성기에는 한국어 교정 연동(`--korean`, `U-11`)이 있다. 교정 제안을 받아 볼 수는 있다
- 다만 교정 결과가 맞는지에 대한 규범 판단은 이 창구가 하지 않는다 — 국립국어원 자료로 확인하도록 안내한다

## [R-04] 그 밖의 범위 밖

- 작업료·단가·정산, 계약, 에이전시·발주처 연락처
- 디즈니+·쿠팡플레이 등 **넷플릭스 외 발주처의 규정 수치** — 공개 근거 문서가 없다. 발주처 가이드를 확인하도록 안내한다
- 넷플릭스 비공개 포털 자료(음역 지침, KNP 도구 사용법)
- 자막 생성기와 무관한 프로그램 사용법(다른 자막 편집기·동영상 플레이어 등)
- 영상·대본 내용 자체에 대한 번역 요청
- 넘길 때: 이 창구에서 근거를 갖고 답할 수 없는 질문이라고 밝히고, 확인할 곳이 분명하면 그곳을 알려 준다. 모르면 모른다고 한다

## [R-05] 넘기기와 담당자 이관의 차이

- 넘기기(이 문서): 이 창구가 다룰 **대상이 아닌** 질문
- 확신 부족: 대상일 수도 있는데 카테고리 판정 확신이 낮은 질문 — 판정 단계의 게이트가 따로 처리한다
- 둘을 섞지 않는다 (전날 실습 교훈: 이관 대상을 범위 밖으로 밀어 넣으면 조용히 틀린다)
