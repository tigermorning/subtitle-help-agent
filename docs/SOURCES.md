## 수집 중 발견한 것

- **넷플릭스 프레임 간격 규정은 삭제되지 않았다**
  - General Requirements 변경 기록(2020-07-24): 타이밍·프레임 간격 절을 **이 글에서** 뺐다
  - 3일 뒤(2020-07-27) Subtitle Timing Guidelines가 공개됐고, 5절에 "최소 2프레임"이 그대로 있다
- **최소 노출 시간 초 표기가 두 문서에서 다르다**
  - General Requirements: 5/6초(24fps에서 20프레임)
  - Timing Guidelines: 20프레임(또는 4/5초)
  - 프레임 수는 같고 초 환산만 다르다. 평가 문항으로 쓸 만하다
- **한국어 가이드가 넘기기 경로를 직접 지시한다**
  - `KO-I.21`: 가이드에 없는 언어 문제는 국립국어원을 참고하라
  - 같은 조항의 띄어쓰기 지침·맞춤법 검사기 주소 2건은 접속되지 않았다
- **한국어 줄당 글자 수 한도가 둘이다**
  - FAQ(215274938): 자동 QC 반려선 23자, 넷플릭스 오리지널은 16자
  - 한국어 가이드는 16자만 적는다(`KO-I.2`)
- **옛 FAQ와 최근 문서가 어긋난다**
  - 한국어 판권 콘텐츠 에피소드 제목 FAQ(2019)는 한국어를 따로 다룬다
  - 제목 번역 문서(360000586227)는 2024-04-05에 "한국어를 다르게 다루던 내용을 삭제했다"고 적었다
- **2025년 12월 개정 목록에 한국어는 없다** — 한국어 가이드 최신 개정은 2025-07-07
- **SDH 화자 표시 괄호 표기 불일치**
  - `KO-II.8` 원문은 "parentheses"라고 적었지만 예시는 모두 대괄호 `[ ]`다
