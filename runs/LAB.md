# 실험 기록 — 자막 생성기 소통 창구 에이전트

- 규칙
  - eval 분할은 프롬프트에 넣지 않는다
  - 한 번에 하나만 바꾼다
  - 바꾼 것과 숫자를 적는다. 흔들림이 의심되면 두 번 잰다
- 근거는 평가셋이 아니라 `docs/`(근거 문서·매핑표)에서만 가져온다
- 로그: `runs/<번호>-<이름>.log`, 결과 원본: `runs/<번호>-<이름>.json`

- 1차에서 고친 것
  - `U-006`: 채점기가 must 항목 하나를 판정 목록에서 빠뜨렸는데 통과로 셌다 → 항목 번호로 판정받고, 빠지면 한 번 더 묻고, 그래도 빠지면 누락으로 센다
  - `F-001`: 모범 답안이 "(접수번호 안내)" 자리표시라 접수번호가 없었다 → 예시 접수번호로 채움

- 검증기(`guardrail.py`)도 모범 답안으로 돌렸다: 1차 1/51 위반
  - `O-008` 모범 답안이 근거 조각(R-04)에 없는 `--translate`를 언급 — 검증기가 맞았다. 모범 답안을 고침
